## ⚙️ Installation & Setup

Follow these steps to run the portfolio website locally.

### 1. Clone the Repository

```bash
git clone https://github.com/indratumu296-web/My-Portfolio.git
```

### 2. Navigate to the Project Folder

```bash
cd My-Portfolio
```

### 3. Open the Project

Open the project folder in Visual Studio Code.

```bash
code .
```

### 4. Run the Website

You can open `index.html` directly in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code:

1. Install Live Server.
2. Open `index.html`.
3. Right-click the file.
4. Select **Open with Live Server**.
5. View the portfolio in your browser.

No Node.js installation or backend server is required for the current static portfolio implementation.
